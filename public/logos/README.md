# Platform Logo Watermarks

Upload your flat white / light-grey SVG or PNG logo files here with these **exact filenames**:

| Platform     | Filename                        |
|--------------|---------------------------------|
| Squarespace  | `squarespace-mark-white.svg`    |
| Wix          | `wix-mark-white.svg`            |
| Shopify      | `shopify-mark-white.svg`        |
| WordPress    | `wordpress-mark-white.svg`      |

## Tips
- Use **SVG** if possible — scales infinitely with zero blur at any size.
- If you only have a PNG, rename it with the same name but `.png` extension
  and update the `src` in `src/components/PlatformDeepDive.tsx` accordingly.
- The logo should be **flat white** (`#FFFFFF`) or **very light grey** (`#F5F5F5`)
  on a **transparent background** — no coloured fills.
- Get official press/brand assets from:
  - Squarespace: https://www.squarespace.com/press
  - Wix: https://www.wix.com/press-room/home
  - Shopify: https://www.shopify.com/brand-assets
  - WordPress: https://wordpress.org/about/logos/
